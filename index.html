overall

Overall score

四個 component 的加權總分；coverage 另外受到 kinematic 與 safety gate。

優點

  • 同時考慮運動真實性、安全性、異質互動與多樣性。
  • Coverage gate 降低用不安全亂撒軌跡換取 diversity 的誘因。
  • 保留 component scores，方便追查總分來源。

限制

  • 單一總分會掩蓋完全不同的 failure modes。
  • 各 component 的數值尺度不同，nominal weight 不等於實際區辨力。
  • Safety 接近飽和、coverage 偏低時，排名主要由 kinematic 與 cross-type 決定。

kinematic_realism

Kinematic realism

比較預測與 GT 的速度、加速度、角速度、角加速度分布，並以 GT oracle ceiling 正規化。

優點

  • 能抓出抖動、急轉、速度不合理等 ADE 不容易描述的問題。
  • 使用 oracle normalization，降低場景本身可預測性造成的尺度差異。
  • 按 agent type 平衡，不會由數量最多的 vehicle 完全主導。

限制

  • 只看邊際運動分布，不能保證 route 或 intent 正確。
  • 只有一個 selected agent 的場景，scenario score 對單一異常非常敏感。
  • 單一 rollout 影片未必能呈現 32-rollout likelihood 的完整失敗。

safety

Safety

碰撞安全分數與 road-edge valid-region 分數各占一半。

優點

  • 碰撞使用 box overlap 並容許 0.1 m annotation tolerance。
  • 同時處理 collision 與 map-validity，不只看其中一項。
  • 提供 unsafe rate 與樣本數，容易定位 edge cases。

限制

  • 以 timestep unsafe rate 計分，短暫事件可能被大量正常 frames 稀釋。
  • Valid region 依賴 road-edge annotation，對地圖邊界誤差敏感。
  • Road-edge valid region 不等於 drone footage visibility boundary。

cross_type_interaction

Cross-type interaction

比較 vehicle、two-wheeler、pedestrian 之間的距離與 time-to-proximity 分布。

優點

  • 針對 HetroD 的 heterogeneous traffic 核心問題。
  • 能發現沒有碰撞、但互動節奏與 GT 明顯不同的模型。
  • 依 pair type 平衡，避免某一種互動完全主導。

限制

  • 只有 1–3 個 included pairs 時，scenario score 變異很大。
  • Histogram similarity 不容易從單一 rollout 影片直觀看出。
  • 低分代表與 GT 分布不同，不一定代表危險或碰撞。

coverage

Coverage / diversity

在 0.5 m occupancy grid 上衡量 32 rollouts 的 incremental box-union diversity。

優點

  • 能直接偵測 32 rollouts 完全重疊的 mode collapse。
  • 只統計 valid region 內 occupancy，減少用出界軌跡增加多樣性。
  • 以 agent type 彙整並回報 occupancy union area。

限制

  • 對 grid resolution、agent footprint 與 rollout 數量敏感。
  • 合理但相近的 trajectories 也可能得到接近零分。
  • 需要更多 baselines 校準，確認 diversity 分數與人類判斷一致。
